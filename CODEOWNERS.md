# Code ownership

GitHub's machine-readable ownership rules are in [`.github/CODEOWNERS`](.github/CODEOWNERS). Changes to application code, Worker configuration, deployment automation, and security-sensitive files require maintainer review.

The current fallback owner is `support@teampsmpv.com`. A repository administrator should replace it with a verified GitHub user or organization team such as `@TEAM-PSMPV/website-maintainers` after that team exists and has write access.
