# Support

- Product or website help: email `support@teampsmpv.com` or use the website contact page.
- Reproducible website bug: open a GitHub issue with browser, device, URL, expected behavior, actual behavior, and screenshots when safe.
- Security vulnerability: follow [SECURITY.md](SECURITY.md); never disclose it publicly.

Please do not include credentials, personal data, private client information, or API tokens in any issue.
